# Lantern Animation

Lantern Animation built with HTML, CSS and JavaScript.

![Preview](./Screenshot%202024-08-25%20202409.png)

A small, lightweight animated lantern effect created using HTML/CSS and a bit of JavaScript. Great as a decorative element for web pages, headers, or as a tiny CSS/JS demo.

## Demo

Open `index.html` in your browser to see the animation. The preview image above shows the finished effect.

## Features

- Purely front-end (HTML, CSS, JS)
- Smooth, performant animation using CSS transforms and keyframes
- Easy to customize color, speed, and size via the stylesheet
- Small and dependency-free

## How to run

1. Clone the repository:

   ```bash
   git clone https://github.com/BinaryVortex/Lantern-Animation.git
   cd Lantern-Animation
   ```

2. Open `index.html` in your browser (double-click or use a local server):

   ```bash
   # using Python 3 built-in server (optional)
   python -m http.server 8000
   # then visit http://localhost:8000
   ```

## Customize

- Edit the CSS files (typically `styles.css` or `main.css`) to change colors, sizes, and animation timings.
- If there's a `script.js`, tweak timing or interaction behavior there.

## Files

- `index.html` — page that contains the lantern markup
- `styles.css` — animations and styling
- `script.js` — optional JavaScript for interaction (if present)
- `Screenshot 2024-08-25 202409.png` — preview image used in this README
